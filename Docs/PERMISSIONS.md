# İzin metinleri

| İzin | Kullanım |
|---|---|
| Kamera | Canlı önizleme ve kullanıcı tarafından başlatılan fotoğraf/video çekimi |
| Mikrofon | Sesli video kaydı |
| Fotoğraflar (yalnızca ekleme) | Kullanıcının seçtiği tamamlanmış videoyu Fotoğraflar’a aktarma |
| Hareket | Sonraki iterasyonda kullanıcı etkinleştirdiğinde sabitleme özellikleri |
| Bildirim | Sonraki iterasyonda kullanıcı etkinleştirdiğinde kayıt/koruma uyarıları |

İzinler, özelliğin ilk kullanımından önce nedenleri açıklanarak istenir. Reddedilmiş bir izin için uygulama erişim varmış gibi davranmaz; kullanıcı sistem Ayarları’na yönlendirilir.
